## Use

- A fluid editor with consistent controls and component treatments throughout the app.
- One shared **Coming soon** badge, in the same right-hand position on both Upload floor plan and Scan Room. Status does not belong in the descriptive text.
- Functional, specific headings and short explanations of actions.
- Plain **ois designs** text in the app. The latest instruction removes the company image logo and supersedes the earlier logo-integration studies.
- Home Planner AI: Room Design 3D, pink logo, by Room Planner Ltd, as a major workflow reference. Verify claims about its UI and distinguish inspiration from our own decisions.
- Reasoned evaluation: defend a design when justified, or correct it with an explanation. Do not merely agree with criticism.
- Short point-form chat responses. Answer questions before making the requested changes when the user explicitly requests that order.
- Door choices including swinging, sliding and double doors. Show placement dimensions from both room-facing sides of a shared wall.
- A plan that explicitly handles different ceiling heights.
- Keep ceiling height on the same dimensions page as width and depth, with metres/feet selection.
- Generic creation entry: select a room type or whole floor plan, then a starting shape or draw from scratch. Keep the first three creation options.
- Clear project design navigation, with one entry point per action on each screen. Prioritise the room visual over persistent controls.
- Furniture moves directly by dragging in both 2D and 3D, with optional quick moving of unlocked items, per-item lock/unlock, and a walkthrough mode that blocks all editing.
- Undo/redo use accessible icon buttons. No Centre item or furniture nudge/directional control buttons.
- At least ten visibly distinct flooring materials, wall colour wheel/HEX, wall textures and sheens; colour variants alone do not count as flooring choices.
- Baseboard profiles, height, projection, finish and door/corner handling. Optional close-up measurements/photos for matching actual trim.
- Door type selection uses visual examples; position doors on the actual floor plan. Retain last-used door settings and support repeat placement.
- Real 3D furniture assets developed alongside the manual editor, before scanning. Cover all rooms, coordinated themes, colour/material variants, bed sizes/types, search and useful filters.
- A reusable sourced Home Planner reference file, with verified behaviour separated from unknowns and OIS-specific decisions.
- After this design round is approved, guide setup and recreate the approved design in Expo using a complete parity checklist. Do not silently omit features or begin app implementation before that approval.

- Unrequested slogans or marketing filler. Specifically rejected: “Build the plan. Make it yours.”, “Your space, considered”, and “Plan with clarity”. Apply this correction to similar filler elsewhere, including the catalogue and upload screens.
- Inconsistent availability labels, duplicated navigation and forced next-step buttons for tasks users should be able to choose in the editor.

- Obvious commentary such as “Living room and kitchen share one wall”. Keep instructions only when needed to use a control or understand a state.
- Repeated Add actions on the same screen, unexplained navigation after removing tabs, and extra pages for closely related dimension fields.
