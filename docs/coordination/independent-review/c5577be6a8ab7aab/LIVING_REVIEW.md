- `barrel-enclosure`, `egg-swivel`, `petal-lounge`: visibly detached or outboard legs relative to curved seat/shell. A newer staged barrel fixture has a connected seat pan/legs; the shared builder fix must reach the other affected exports too.

- `jointed-task-floor`: shade is visibly separated from the articulated arm. Source diagnosis: lathe builds translated vertex coordinates, then rotating its object rotates that translation about the model origin. Local geometry/object placement or an explicit local pivot is required.
